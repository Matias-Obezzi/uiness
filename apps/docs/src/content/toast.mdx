Notifications that stack with the newest in front, expand when you hover the stack, swipe away, pause their timers while you look at them, and follow your promises from loading to done. Driven by a `toast()` function you can call from anywhere.

## Usage

Mount `<Toaster />` once, near the root, then call `toast()`.

```tsx
import { Toaster, toast } from '@/components/ui/toast'

function App() {
  return (
    <>
      <Toaster />
      <Page />
    </>
  )
}

toast('Event has been created')
toast.success('Saved', { description: 'All changes are in.' })
```

## Actions

`action` renders a primary button that closes the toast after its handler runs, unless the handler calls `event.preventDefault()`. `cancel` renders a secondary one.

## Undo, repeats and time left

`toast.undo()` says something happened with an Undo button, and resolves `true` when it was used, `false` once the toast leaves any other way, so the change can be made right away and taken back if asked. A toast with the same type, title and description as one already showing folds into it instead of stacking: it counts up (×3) and starts its time again. `dedupe: false` keeps them apart. `progress` adds a bar that empties as the time runs out, and waits with the timer while the pointer is over the toasts.

<ComponentPreview name="toast-more" />

```tsx
archive(message)
if (await toast.undo('Message archived')) unarchive(message)

toast('Draft saved', { progress: true })

const id = toast.loading('Uploading')
toast.update(id, { title: 'Uploaded', type: 'success' })
toast.isActive(id) // false once it leaves
```

## Options

| Option | Description |
| --- | --- |
| `id` | Reuse to update a toast in place. |
| `title`, `description` | Content. |
| `type` | `default`, `success`, `error`, `info`, `warning`, `loading`. Also available as `toast.success()` and friends. |
| `icon` | Replace the type icon, `null` hides it. |
| `duration` | Auto dismiss in ms, `Infinity` to keep. Loading toasts default to `Infinity`. |
| `action`, `cancel` | `{ label, onClick }` buttons. |
| `dismissible` | Swipe and close button. Default true. |
| `closeButton`, `position`, `important` | Per toast overrides of the Toaster settings. |
| `onDismiss`, `onAutoClose` | Callbacks. |
| `progress` | A bar that empties as the time runs out. Overrides the Toaster setting. |
| `dedupe` | Fold into an identical toast already showing. Default `true`, for string titles. |

`toast.dismiss(id)` closes one toast, `toast.dismiss()` closes them all.

## `<Toaster />` props

| Prop | Default | Description |
| --- | --- | --- |
| `position` | `'bottom-right'` | Any corner, or the center of the top and bottom edges. |
| `expand` | `false` | Keep the stack expanded instead of collapsing it until hovered. |
| `visibleToasts` | `3` | Toasts visible in the collapsed stack. |
| `richColors` | `false` | Colored backgrounds for success, error, info and warning. |
| `closeButton` | `false` | Close button on every toast. This site turns it on. |
| `duration` | `4000` | Default auto dismiss delay. |
| `gap`, `offset` | `14`, `24` | Spacing in px. |
| `icons` | | Custom icons per type. |
| `toastClassName`, `toastStyle` | | Applied to every card. |
| `label`, `closeLabel` | `'Notifications'`, `'Close'` | Names of the region and of the close button. The registry `Toaster` fills them from its [labels](#labels). |
| `progress` | `false` | A bar on every toast that empties as its time runs out. Hidden with reduced motion. |
| `hotkey` | `['altKey', 'KeyT']` | Keys that move focus to the toasts. `false` turns it off. |

## Theming

The wrapper maps the cards to `--popover`, `--border`, `--radius` and the action button to `--primary`. Override any of the toast variables through `style`:

```css
--toast-bg, --toast-color, --toast-border, --toast-shadow, --toast-radius, --toast-width,
--toast-action-bg, --toast-action-color,
--toast-success-bg, --toast-success-color, --toast-success-border (and error, info, warning)
```

## Accessibility

The region is labelled "Notifications". Each toast is a polite live region, or assertive with `important`. Timers pause while hovering and while the page is hidden, and swipe is only one way to dismiss: the close button and the actions work with a keyboard too.

Alt+T moves focus to the toasts, announced through `aria-keyshortcuts`. While focus is inside, the stack stays open and the timers wait, the way they do under the pointer, so there is time to reach an action with Tab. Change the keys with `hotkey`, as `KeyboardEvent.code` with modifier names, or turn it off with `false`.

## Toast or Island?

Both are transient messages. [Island](/docs/island) is a single spot at the top that morphs between states, good for one live activity or a confirm. Toasts stack, so they fit streams of events. They share the promise API, so switching is a one line change.

## Labels

Every word it shows or reads out to screen readers, in English by default. The registry `Toaster` takes them as `labels`. To set them for the whole app, put them under `'toast'` in a [`LabelsProvider`](/docs/localization). Functions get the numbers and names that go in the sentence.

```ts
const defaultToastLabels: ToastLabels = {
  region: 'Notifications',
  close: 'Close',
}
```
