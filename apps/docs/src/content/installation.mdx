The registry works with the CLI you likely already use to add components to a Tailwind project. Register uiness once, then add items by name.

## Register the registry

Add the `@uiness` namespace to the `registries` field of your `components.json`. If the file does not exist yet, run `npx shadcn@latest init` first.

<RegistryConfig />

## Add the theme

The theme item writes the CSS variables for light and dark mode into your globals. It also installs `tw-animate-css`, which the overlays use for their enter and exit animations.

<Install name="theme" />

Make sure your global CSS imports both:

```css
@import "tailwindcss";
@import "tw-animate-css";

@custom-variant dark (&:is(.dark *));
```

## Add components

<Install name="button" extra="Dependencies and the cn() helper are installed along with it." />

Then import from wherever your components live:

```tsx
import { Button } from '@/components/ui/button'

export function Page() {
  return <Button>Hello</Button>
}
```

Several items at once:

```bash
npx shadcn@latest add @uiness/dialog @uiness/dropdown-menu @uiness/island
```

## Add blocks

Blocks are whole page sections, a hero, a pricing table, a footer, made from the components here. They install the same way, bring the components they use with them, and land in `components/` rather than `components/ui`, since they are meant to be edited:

```bash
npx shadcn@latest add @uiness/hero-01
```

```tsx
import { Hero01 } from '@/components/hero-01'
```

Every block takes its copy through props and lays itself out with container queries, by the width of wherever you put it.

## Packages

`island`, `image`, `fx` and `toast` are registry items too. They install the npm package and drop a thin wrapper in `components/ui` that connects the package to your theme tokens. You can also use the packages directly without the registry:

```bash
pnpm add @uiness/image @uiness/island @uiness/fx @uiness/toast @uiness/scroll
```

## Manual installation

Every registry item is a JSON file with the source inline, so you can copy files by hand: open <RegistryLink name="button" />, paste the content of each file into your project, and install the dependencies it lists.

## Next.js

The components that hold state start with `'use client'`, so they can be imported from server components directly. The packages ship with the same directive.
