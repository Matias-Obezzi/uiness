Tiles rearranged in two directions, the way a home screen moves its icons. Dropping between two tiles on a row does what it looks like it does, because the hit test reads the boxes in reading order.

## Usage

```tsx
import { ReorderableGrid, ReorderableGridItem } from '@/components/ui/reorderable-grid'

const [ids, setIds] = useState(['mail', 'calendar', 'notes', 'camera'])

<ReorderableGrid items={ids} onReorder={setIds} columns={4}>
  {(id) => (
    <ReorderableGridItem key={id} id={id}>
      {labels[id]}
    </ReorderableGridItem>
  )}
</ReorderableGrid>
```

`columns` sets the template and is also what the up and down arrow keys step by, so a press moves a whole row while left and right move a single cell. Tiles are square and dragged from anywhere on them: one this small has no room for a handle.

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `items` | | Item ids, in their current order. Unique and stable. |
| `onReorder` | | `(items, change) => void`, once, on a drop that moved something. |
| `columns` | `4` | Tiles per row, and what up and down step by. |
| `disabled` | | Turns dragging off and dims the grid. |
| `activationDistance` | `4` | Pixels the pointer must travel before the drag starts. |
| `announcements` | | Override any of the four screen reader messages. |
| `roleDescription` | `'grid item'` | What a screen reader calls a tile. |
| `children` | | `(id, index) => ReactNode`. One tile per id. |
| `overlay` | | `(id) => ReactNode`. A copy that follows the pointer. |

`<ReorderableGridItem>` takes the `id` it renders.
