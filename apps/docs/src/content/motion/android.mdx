## Usage

```tsx
import { Android } from '@/components/ui/android'

<Android src="/android-app.png" alt="Android App Screenshot" />
```

Rendered entirely with inline CSS and SVG geometry, requiring zero static device PNG assets. Scales fluidly with its container and supports both static screenshots and interactive children.

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `src` | `undefined` | Screenshot image URL to render on the screen. |
| `videoSrc` | `undefined` | Video clip URL to loop on the screen. |
| `children` | `undefined` | Interactive React elements rendered on the screen. |
| `alt` | `'Android screen'` | Accessible alt text for screen media. |
