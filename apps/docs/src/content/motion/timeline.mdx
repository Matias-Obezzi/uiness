Entries down a vertical line that lights up as you scroll. Each entry's dot turns on when it passes the reading position, and its heading sticks while its content scrolls by.

## Usage

```tsx
import { Timeline, TimelineItem } from '@/components/ui/timeline'

<Timeline>
  <TimelineItem date="March 2026" title="Launch">
    <p>What happened.</p>
  </TimelineItem>
</Timeline>
```

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `color` | primary | Color of the lit part of the line. |
| `anchor` | `0.6` | Where on the screen the line catches up with you, 0 to 1. |

`TimelineItem` takes `date`, `title` and `icon`, which replaces the dot.

## Pure CSS

The timeline runs no JavaScript, so it works as a server component and with JavaScript turned off. The line and the dots run on CSS scroll-driven animations: the timeline declares a view timeline whose viewport is cut down to a line at `anchor`, and the lit part of the line grows along it with `animation-timeline`. Each entry has a view timeline of its own, and its dot lights up over the first `2rem` of scrolling past the anchor.

Browsers without scroll-driven animations show the line fully lit and every dot on. Support: Chrome and Edge 115 and later, Opera 101 and later, Safari 26 and later. Firefox has them only behind a flag at the time of writing.

A CSS view timeline follows the nearest scroll container, and an ancestor with `overflow: hidden` counts as one even though it never scrolls. Between the timeline and the page, use `overflow: clip` instead, which does not create a scroll container.

## Layout

The layout follows the timeline's own width with container queries, not the screen's: from `42rem` wide each date sits in a sticky column beside its entry, and below that it goes above the entry. The same timeline fits a full page and a narrow column.
