Plays a transition when its content scrolls into view. With `stagger`, each child follows the previous one.

<Install name="reveal" />

## Usage

```tsx
import { Reveal } from '@/components/ui/reveal'

<Reveal variant="up">
  <Card />
</Reveal>

<Reveal stagger={100} className="grid grid-cols-3 gap-4">
  <Card /><Card /><Card />
</Reveal>
```

With `stagger` the children are cloned with a `style` and a `data-state`, so they have to be elements that accept both, which every HTML element and every component here does.

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `variant` | `'up'` | `fade`, `up`, `down`, `left`, `right`, `blur` or `scale`. |
| `duration` | `700` | Milliseconds the transition takes. |
| `delay` | `0` | Milliseconds before it starts. |
| `stagger` | | Milliseconds between children. |
| `repeat` | `false` | Play again every time it scrolls into view. |
| `amount` | `0.2` | How much has to be visible first. |
