Replaces the system cursor with a custom element inside a container region, automatically restoring the native cursor over text inputs.

## Usage

```tsx
import { Pointer } from '@/components/ui/pointer'

<div className="relative overflow-hidden">
  <Pointer>
    <span className="rounded-full bg-primary px-2 py-1 text-xs text-primary-foreground">
      Editor
    </span>
  </Pointer>
  ...
</div>
```

The pointer only activates on devices with fine pointing input (`(hover: hover) and (pointer: fine)`), leaving touch screens unaffected. When hovering editable elements (`input`, `textarea`, `select`, `contenteditable`), the custom pointer hides itself and native cursor styling is restored. Position updates write directly to `translate3d` via DOM references for silky smooth movement without frame latency.

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `hotspot` | `[0, 0]` | Pixel offset `[x, y]` of the cursor's active clicking tip. |
| `children` | SVG arrow | Custom pointer element, emoji or markup. |
