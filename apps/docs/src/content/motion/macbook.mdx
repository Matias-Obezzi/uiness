## Usage

```tsx
import { MacBook } from '@/components/ui/macbook'

<MacBook src="/desktop-app.png" alt="Desktop Web App" />
```

Constructed with precision CSS border radii and notch details, matching modern 16:10 laptop screen proportions.

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `src` | `undefined` | Screenshot image URL to render on the screen. |
| `videoSrc` | `undefined` | Video clip URL to loop on the screen. |
| `children` | `undefined` | Interactive React elements rendered on the screen. |
| `alt` | `'MacBook screen'` | Accessible alt text for screen media. |
