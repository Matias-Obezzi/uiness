Everything is driven by CSS variables: colors, layers, motion and type. Change them once and every component, the island and the image wrappers follow.

## Variables

The theme item defines these on `:root` and again on `.dark`:

| Variable | Used for |
| --- | --- |
| `--background`, `--foreground` | Page surface and text. The island uses the foreground color as its background. |
| `--card`, `--card-foreground` | Cards. |
| `--popover`, `--popover-foreground` | Menus, popovers, tooltips. |
| `--primary`, `--primary-foreground` | Primary buttons, checked controls, confirm buttons. |
| `--secondary`, `--secondary-foreground` | Secondary buttons and badges. |
| `--muted`, `--muted-foreground` | Subtle backgrounds, helper text, image placeholders. |
| `--accent`, `--accent-foreground` | Hover and focus surfaces. |
| `--destructive` | Danger buttons and destructive menu items. |
| `--border`, `--input`, `--ring` | Borders, field borders, focus rings. |
| `--radius` | Base corner radius. Sizes derive from it. |

Colors are written in `oklch`, which keeps contrast even across hues when you shift a value.

```css
:root {
  --radius: 0.75rem;
  --background: oklch(1 0 0);
  --foreground: oklch(0.145 0 0);
  --primary: oklch(0.205 0 0);
  --primary-foreground: oklch(0.985 0 0);
  /* ... */
}

.dark {
  --background: oklch(0.145 0 0);
  --foreground: oklch(0.985 0 0);
  --primary: oklch(0.922 0 0);
  --primary-foreground: oklch(0.205 0 0);
  /* ... */
}
```

## Layers

Everything that stacks takes its `z-index` from one scale, so a menu opened inside a dialog lands above it, a toast never hides under a sticky header, and a card being dragged floats over all of them.

| Variable | Value | Used by |
| --- | --- | --- |
| `--z-raised` | `10` | A dragged row, a focused segment: above its siblings, nothing more. |
| `--z-sticky` | `40` | Navbar, bottom tab bar, the docs header. |
| `--z-overlay` | `50` | Dialog, drawer, gallery lightbox and their backdrops. |
| `--z-popover` | `60` | Dropdown menu, select, popover, link preview. Above overlays, since they open inside them. |
| `--z-toast` | `70` | The toaster and confetti. |
| `--z-tooltip` | `80` | Tooltips. |
| `--z-drag` | `90` | Whatever is under the pointer mid drag. |
| `--z-island` | `100` | The Dynamic Island. |

Components read them as `z-(--z-overlay,50)`. The fallback keeps an item working when it is installed without the theme, and the gaps between steps leave room for your own layers:

```css
:root {
  --z-cookie-banner: 65; /* above menus, below toasts */
}
```

The packages follow the same scale when the variables exist: `@uiness/island` reads `--z-island`, `@uiness/toast` reads `--z-toast` and the `@uiness/dnd` overlay reads `--z-drag`.

## Motion

Durations and easings every component shares, so the interface moves at one pace. Change `--duration-normal` and every dialog follows.

| Variable | Value | Used for |
| --- | --- | --- |
| `--duration-instant` | `100ms` | Presses and toggles. |
| `--duration-fast` | `150ms` | Menus, popovers, tooltips, selects. |
| `--duration-normal` | `200ms` | Dialogs and their backdrop. |
| `--duration-slow` | `300ms` | Drawers, sidebars, the navbar hiding on scroll. |
| `--duration-slower` | `500ms` | Larger moves, like the link preview springing open. |

Easings come as variables and as Tailwind utilities:

| Utility | Variable | Feel |
| --- | --- | --- |
| `ease-standard` | `--easing-standard` | Everyday transitions. |
| `ease-emphasized` | `--easing-emphasized` | Entrances that land softly. [Choreo](/docs/choreo) uses it by default. |
| `ease-exit` | `--easing-exit` | Things leaving, quick to go. |
| `ease-sheet` | `--easing-sheet` | Panels sliding from an edge. |
| `ease-spring` | `--easing-spring` | A small overshoot, built with `linear()`. |

```tsx
<div className="transition-transform duration-(--duration-slow) ease-emphasized" />
```

With `prefers-reduced-motion` the theme cuts every animation and transition short.

## Typography

`--font-sans` and `--font-mono` set the families; point them at your fonts. On top of Tailwind's sizes there is a scale of finished text styles, each carrying its line height, tracking and weight. Display and title scale with the viewport.

| Utility | Size | For |
| --- | --- | --- |
| `text-display` | `2.5rem` to `4.5rem` | Hero headlines. |
| `text-title` | `1.875rem` to `2.5rem` | Page titles. |
| `text-heading` | `1.5rem` | Section headings. |
| `text-subheading` | `1.125rem` | Card titles and small headings. |
| `text-lead` | `1.25rem` | The paragraph under a headline. |
| `text-body` | `1rem` | Long reading, with a relaxed line height. |
| `text-caption` | `0.8125rem` | Labels and notes. |
| `text-eyebrow` | `0.75rem` | The small caps line above a heading, with `uppercase`. |

```tsx
<p className="text-eyebrow text-muted-foreground uppercase">New</p>
<h1 className="text-display">Pages that move</h1>
<p className="text-lead text-muted-foreground">One line on what it is.</p>
```

## Dark mode

Dark mode is class based. Add `dark` to the `html` element and everything switches. The docs site stores the choice in `localStorage` and applies it before the first paint with a tiny inline script, which avoids a flash of the wrong theme.

```html
<html class="dark">
```

## Tailwind

The theme file maps each variable to a Tailwind color through `@theme inline`, so `bg-primary`, `text-muted-foreground` or `border-border` work as utilities.

```css
@theme inline {
  --color-primary: var(--primary);
  --color-primary-foreground: var(--primary-foreground);
  --radius-lg: var(--radius);
}
```

## A brand color

Point `--primary` at your brand and keep `--primary-foreground` readable against it. Then decide whether the island should follow: by default it uses `--foreground`, which reads as a black pill on light pages and a light pill on dark pages. Set `--island-bg` on the island wrapper to change that.

```tsx
<Island style={{ '--island-bg': 'var(--primary)', '--island-color': 'var(--primary-foreground)' }} />
```
