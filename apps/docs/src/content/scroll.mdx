Scroll-linked motion primitives. The progress of any element through the viewport, parallax that writes straight to the DOM, and the section being read. Zero dependencies, and the core works without React.

## Progress

```tsx
import { useScrollProgress } from '@uiness/scroll'

const ref = useRef<HTMLDivElement>(null)
const progress = useScrollProgress(ref, { offset: ['start end', 'end start'] })
```

An offset pair says when progress is 0 and when it is 1. Each entry reads `"<element edge> <viewport edge>"`: `'start end'` means the top of the element meets the bottom of the viewport, `'end start'` means the bottom of the element meets the top. Edges are `start`, `center`, `end`, a number from 0 to 1, or a pixel string like `'80px'`.

`useScrollEffect(ref, callback, options)` runs a callback instead of updating state, at most once per frame, for when you want to write a style yourself.

## Parallax

<ComponentPreview name="scroll-parallax" />

```tsx
useParallax(ref, { speed: 0.3 })
```

`speed` is how far the element travels over its trip through the viewport, as a fraction of the viewport. Positive lags behind the page, negative runs ahead. The hook writes a `translate` to the element, so nothing re-renders.

## Active section

```tsx
const active = useActiveSection(listRef, { anchor: 0.5 })
```

The index of the child of `listRef` closest to a line across the viewport. Drives panels that change with the section being read; see [Sticky Scroll](/docs/motion/sticky-scroll).

## Direction, velocity and sticky

<ComponentPreview name="scroll-direction" />

```tsx
const direction = useScrollDirection({ threshold: 12 }) // 'up' | 'down' | null
const velocity = useScrollVelocity() // px/s, 0 at rest
const stuck = useStuck(headerRef) // pinned at its `top`
```

`useScrollDirection` flips only after `threshold` pixels the other way, so a trackpad's jitter does not hide and show a header in turn. `useScrollVelocity` reads at most once per frame and settles to 0 when the scrolling stops, for things that react to speed. `useStuck` tells whether a `position: sticky` element is pinned at its offset, to give it a shadow or a smaller size once it is. All three follow the page, or the scrolling box passed as `container`.

## Horizontal

Every hook takes `axis: 'x'`: progress through a row, parallax sideways, the card in the middle of a row, which way it scrolls (`left` and `right`), its speed, whether a sticky column is pinned, and scrolling to a card. A list that is its own scroller, like a row of cards, is measured against itself. Two more are for rows only: `useScrollEdges` says whether it is at the start or the end, for arrows that disable themselves, and `useHorizontalWheel` lets a mouse wheel scroll the row sideways, handing the wheel back to the page at either end and leaving trackpads that already scroll sideways alone.

<ComponentPreview name="scroll-horizontal" />

```tsx
const active = useActiveSection(rowRef, { axis: 'x' })
const { atStart, atEnd } = useScrollEdges(rowRef)
useHorizontalWheel(rowRef)

scrollToElement(card, { axis: 'x', offset: 16 })
```

## Scrolling to an element

```tsx
await scrollToElement(section, { offset: 64, duration: 800 })
```

`scroll-behavior: smooth` lets you choose neither the time nor the curve, and does not leave room for a sticky header. `scrollToElement` stops `offset` pixels short, takes `duration` ms with any `easing`, stops the moment the reader scrolls themselves, and jumps straight there for readers who ask for reduced motion.

## Locking the page

```tsx
useScrollLock(open)
```

Stops the page from scrolling while a modal or a drawer is open, keeping the scrollbar's width as padding so the layout does not jump. Locks nest: the page scrolls again once every one is released. `lockScroll()` returns the release outside React.

`useParallax` stays put for readers who ask for reduced motion.

## Without React

```ts
import { observeScrollProgress, scrollProgress, activeIndexAt, mapRange } from '@uiness/scroll'

const stop = observeScrollProgress(el, { offset: ['start end', 'end start'] }, ({ progress }) => {
  el.style.opacity = String(progress)
})
```

`scrollProgress` reads once, `observeScrollProgress` keeps reading, `activeIndexAt` picks the nearest of several elements, and `mapRange` turns a progress into any other range. Pass `container` to follow an element inside a scrolling box instead of the window.

## API

| Export | What it does |
| --- | --- |
| `useScrollProgress(ref, options)` | Progress as state, 0 to 1. |
| `useScrollEffect(ref, callback, options)` | Callback with `progress`, `size`, `viewport`, `position`. |
| `useParallax(ref, { speed })` | Moves the element at another rate. |
| `useActiveSection(ref, { anchor, selector, axis })` | Index of the section under the anchor, down a page or across a row. |
| `useScrollDirection({ threshold, container, axis })` | `'up'`, `'down'`, `'left'`, `'right'` or `null`. |
| `useScrollVelocity({ container })` | Pixels per second, 0 at rest. |
| `useStuck(ref)` | Whether a sticky element is pinned. |
| `useScrollLock(active)`, `lockScroll()` | Stop the page from scrolling. |
| `scrollToElement(el, { offset, duration, easing })` | Scroll there over time, stopping short. |
| `useScrollEdges(ref, axis)` | `{ atStart, atEnd }` of an element's own scroll. Default `x`. |
| `useHorizontalWheel(ref)` | A vertical wheel scrolls the row sideways. |
| `observeScrollDirection`, `observeScrollVelocity`, `isStuck`, `scrollEdges`, `wheelToHorizontal` | The same without React. |
| `scrollProgress`, `observeScrollProgress` | The same without React. |
| `activeIndexAt`, `mapRange`, `clamp`, `lerp` | Helpers. |

Reads use `getBoundingClientRect`, batched to one per frame, and a `ResizeObserver` keeps them right when the element changes size.
