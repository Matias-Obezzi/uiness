Bars per day or per category, side by side or stacked, from a list of series. It is a ready-made [Chart](/docs/components/chart): recharts underneath, with the dates, formats, legend and empty state already handled.

## Usage

```tsx
import { BarChart } from '@/components/ui/bar-chart'

const data = [
  { date: new Date(2026, 8, 1), desktop: 720, mobile: 360 },
  { date: new Date(2026, 8, 2), desktop: 804, mobile: 341 },
  // ...
]

<BarChart
  data={data}
  x="date"
  series={[
    { key: 'desktop', label: 'Desktop' },
    { key: 'mobile', label: 'Mobile', color: 'var(--primary)' },
  ]}
/>
```

Each row holds the x value and one number per series. Dates can be `Date` objects or ISO strings like `2026-09-01`; anything else is shown as it is. A missing value, `null` or not a number, leaves that bar out. Series keys become CSS variables (`--color-desktop`), so keep them to letters, digits, `-` and `_`.

The width follows the container and the x labels thin out until they fit, always keeping the latest one. The y axis starts at zero, since a bar's length is the value.

## Stacked

`stacked` piles the series into one bar per row. Only the outer end of each stack is rounded, whichever series is on top, and a thin gap separates the segments.

## Empty state

When there are no rows, or every value is missing, the chart shows `empty` at the same height, so the page does not jump when data arrives.

## Formatting

Dates show as a short day and month in the reader's locale, with the weekday added in the tooltip. Numbers on the axis are compact (`1.2K`), and exact in the tooltip. Pass `locale` to pin the language, or your own functions:

```tsx
<BarChart
  xFormat={(date) => new Date(date).toLocaleDateString('en-GB', { day: 'numeric', month: 'short' })}
  yFormat={(n) => `$${n.toLocaleString()}`}
  {...props}
/>
```

## Accessibility

The chart takes focus, and the left and right arrow keys move the tooltip through the rows. Screen readers get a summary of the series and the date range. Clicking a legend entry hides or shows its series without repainting the others; the last visible one stays.

With reduced motion the bars appear in place instead of growing.

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `data` | | Rows to plot, in order. |
| `x` | | Key of the x value in each row. |
| `series` | | `{ key, label?, color? }` per series. Colors default to `--chart-1` to `--chart-5` in order. |
| `stacked` | `false` | One bar per row with the series stacked. |
| `height` | `240` | Height of the chart, legend excluded. |
| `xFormat` | short date | Formats x values on the axis and in the tooltip. |
| `yFormat` | compact number | Formats values on the axis and in the tooltip. |
| `locale` | browser | Locale of the default formats. |
| `showGrid` | `true` | Horizontal gridlines. |
| `showLegend` | two series or more | Legend above the chart, click to toggle a series. |
| `empty` | `"No data"` | Shown when there is nothing to plot. |
| `aria-label` | generated | Replaces the generated summary. |

For anything these props do not cover, write the recharts chart yourself inside a [`ChartContainer`](/docs/components/chart).
