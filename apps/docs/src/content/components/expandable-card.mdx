A card in a grid that grows out of its place into a larger view over the page, and folds back into the same place when closed. Click a card.

## Usage

```tsx
import {
  ExpandableCard,
  ExpandableCardContent,
  ExpandableCardDescription,
  ExpandableCardTitle,
  ExpandableCardTrigger,
} from '@/components/ui/expandable-card'

<ExpandableCard>
  <ExpandableCardTrigger>
    <img src="/lofoten.jpg" alt="" />
    <span className="p-4 font-semibold">Lofoten</span>
  </ExpandableCardTrigger>
  <ExpandableCardContent>
    <img src="/lofoten.jpg" alt="" />
    <div className="p-6">
      <ExpandableCardTitle>Lofoten</ExpandableCardTitle>
      <ExpandableCardDescription>Norway · 6 nights</ExpandableCardDescription>
      ...
    </div>
  </ExpandableCardContent>
</ExpandableCard>
```

`ExpandableCardTrigger` is the card in the grid, a button with card styles. Keep what is inside it to text and pictures, or pass `asChild` with an element of your own. `ExpandableCardContent` is the larger view; style its width with `className`, `max-w-2xl` by default.

## How it moves

The card itself grows into the view. When it opens, the view is laid out where it ends up, then its surface starts on the card's exact box, with the card's corners and shadow, and grows into place while the backdrop fades in. The card in the grid hides from the first frame, so there is only ever one of it.

- The surface changes size rather than scale, so text never stretches; the view's contents keep their final layout and the growing surface uncovers them.
- The picture the card and the view share moves from its place in the card to its place in the view, resized so it crops the same way at both ends. It is the first `img`, `video`, `picture` or `canvas` in each, or the element you mark with `data-expandable-card-media`.
- The card's own text rides under the picture and fades out early, and what only the view has (the text, tags and buttons around the picture) fades in once there is room for it.

Closing runs the same path back to wherever the card is now, and the card shows again only once the view has landed on it. Closing while it is still growing, or opening it again while it folds, turns around from wherever it is.

It runs on the Web Animations API, timed from `--duration-slow` and `--easing-standard`, with no animation library. With reduced motion the view fades in over the card instead.

## Focus

The larger view is a dialog. Focus moves into it, Tab stays inside it, the page behind does not scroll, and Escape, a click outside or the close button fold it back. Focus returns to the card it came from. Give it an `ExpandableCardTitle` so it is named; `ExpandableCardDescription` is read after the title.

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `open` / `defaultOpen` / `onOpenChange` | | The open state. `onOpenChange(false)` runs when it starts folding back. |

`ExpandableCardContent` takes `showCloseButton`, `true` by default, and `overlayClassName` for the backdrop.

## Labels

Every word it shows or reads out to screen readers, in English by default. `ExpandableCardContent` takes them as `labels`. To set them for the whole app, put them under `'expandable-card'` in a [`LabelsProvider`](/docs/localization). Functions get the numbers and names that go in the sentence.

```ts
const defaultExpandableCardLabels: ExpandableCardLabels = {
  close: 'Close',
}
```
