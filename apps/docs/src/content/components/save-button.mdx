A bookmark button that files into collections. A tap saves to the last collection used, and a strip opens to move it to another or make a new one; the arrow beside it opens the strip at any time, and a tap on a saved item takes it out.

## Usage

```tsx
import { SaveButton } from '@/components/ui/save-button'

<SaveButton
  collections={collections}
  value={savedIn}
  onValueChange={setSavedIn}
  onCreate={(name) => createCollection(name).id}
/>
```

The strip a save opens closes by itself after a few seconds, unless the pointer or focus is in it. Without `onCreate` there is no "New collection" field.

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `collections` |  | Each `{ id, name }`. |
| `value` |  | The collection it is saved in, or `null`. |
| `onValueChange` |  | Called with a collection’s id, or `null`. |
| `onCreate` |  | Makes a collection from a name and returns its id. |
| `defaultCollection` | the first | Where the first tap saves. |

## Accessibility

The main button is a toggle that says where it is saved. Collections in the strip are toggle buttons marking the current one.

## Labels

Every word it shows or reads out to screen readers, in English by default. `SaveButton` takes them as `labels`. To set them for the whole app, put them under `'save-button'` in a [`LabelsProvider`](/docs/localization).

```ts
export const defaultSaveButtonLabels: SaveButtonLabels = {
  save: 'Save',
  saved: (collection) => `Saved to ${collection}`,
  choose: 'Choose a collection',
  savedTo: 'Saved to',
  newCollection: 'New collection',
  create: 'Create',
  remove: 'Remove from saved',
}
```
