Moves through a long list a page at a time. `Paginator` is ready to drop in: give it the page, the total and a callback, and it works out which pages to list and where the ellipses go. When it is narrower than 28rem, as on a phone, it switches to "Page 3 of 59" between the arrows.

## Usage

```tsx
import { Paginator } from '@/components/ui/pagination'

const [page, setPage] = useState(1)

<Paginator page={page} total={236} pageSize={20} onPageChange={setPage} />
```

`page` starts at 1. `total` is the number of items, not pages; the page count is `total / pageSize` rounded up.

## Which pages show

`boundaries` pages stay at each end and `siblings` pages on each side of the current one. Every gap becomes an ellipsis, except a gap of a single page, which shows that page instead. The list keeps the same length wherever you are, so the buttons do not jump around under the pointer while you click through.

```tsx
<Paginator page={page} total={total} siblings={2} boundaries={2} onPageChange={setPage} />
```

The same logic is exported as `getPageRange(page, pageCount, siblings, boundaries)`, which returns numbers and `'ellipsis-start'` or `'ellipsis-end'`, for a layout of your own.

## Links or buttons

Without `getPageHref` every page is a button that calls `onPageChange`. With it, every page is a real link: it works without script, can be crawled and opens in a new tab with a modified click, while a plain click still goes through `onPageChange` so the app can stay on the page.

```tsx
<Paginator
  page={page}
  total={total}
  getPageHref={(p) => `?page=${p}`}
  onPageChange={(p) => router.push(`?page=${p}`, { scroll: false })}
/>
```

## Compact mode

`compact="auto"`, the default, watches the paginator's own width with a container query, not the screen's, so it also goes compact in a narrow column. Pass `true` or `false` to pick one. `formatCompact` changes the words.

## Props

`Paginator`:

| Prop | Default | Description |
| --- | --- | --- |
| `page` | | Current page, from 1. |
| `total` | | Number of items. |
| `pageSize` | `10` | Items on each page. |
| `onPageChange` | | Called with the page to go to. |
| `siblings` | `1` | Pages on each side of the current one. |
| `boundaries` | `1` | Pages kept at each end, at least 1. |
| `compact` | `'auto'` | Show "Page x of y". `auto` switches below 28rem. |
| `getPageHref` | | Builds the address of a page, making every page a link. |
| `formatCompact` | | `(page, count) => ReactNode` for the compact text. |

## Accessibility

It is a `<nav>` named "Pagination". The current page has `aria-current="page"`, each page is named "Page 4", and the arrows "Go to previous page" and "Go to next page". At either end the arrow is disabled, or loses its link. The compact counter is a polite live region, so moving with the arrows reads out the new page.
