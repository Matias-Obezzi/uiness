## Usage

```tsx
import { Progress } from '@/components/ui/progress'

<Progress aria-label="Upload" value={66} />
```

`value` goes from 0 to 100. The bar animates between values. Name it with `aria-label`, or `aria-labelledby` pointing at a visible label, so screen readers say what is progressing, not only how far.
