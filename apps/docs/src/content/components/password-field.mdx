## Usage

```tsx
import { PasswordField } from '@/components/ui/password-field'

<PasswordField name="password" />
<PasswordField name="new-password" strength rules />
```

The eye button keeps the name "Show password" and says its state with `aria-pressed`, which is how a toggle is meant to be read. Clicking it leaves focus and the caret in the field. When the form is submitted the text is hidden again, so a browser never stores it as plain text.

## Strength

`strength` adds a four segment meter with the level and a hint. The built in scorer looks at length, how many kinds of character are used, and the patterns people lean on: common passwords, runs like `abcd` or `1234`, and repeats. It is exported as `getPasswordStrength` if you want the score elsewhere.

```tsx
import { getPasswordStrength } from '@/components/ui/password-field'

getPasswordStrength('Lantern-fig9')
// { score: 3, label: 'Good', hint: 'A few more characters would make it strong.' }
```

It is a guide while typing, not a security check. Pass your own `getStrength`, for example one built on zxcvbn, and check new passwords against breached lists on the server.

## Rules

<ComponentPreview name="password-field-rules" />

`rules` shows a checklist that ticks off as each one is met. `true` gives a sensible default, or pass your own list of `{ label, test }`. The checklist and the meter are linked to the input through `aria-describedby`, so they are read with it, and the level is announced politely only when it changes.

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `value`, `defaultValue`, `onValueChange` | | The text. |
| `strength` | `false` | Show the meter and hint. |
| `getStrength` | built in | Your own scorer, returning `{ score, label, hint }`. |
| `rules` | | `true` for the defaults, or a list of `{ label, test }`. |
| `revealed`, `defaultRevealed`, `onRevealedChange` | | Whether the text shows. |
| `revealLabel` | `'Show password'` | Name of the eye button. |
| `autoComplete` | | `new-password` when there is a meter or rules, `current-password` otherwise. |
| `inputClassName` | | Classes for the input. `className` goes on the wrapper. |

## Labels

Every word it shows or reads out to screen readers, in English by default. `PasswordField` and `PasswordStrengthMeter` take them as `labels`, and `getPasswordStrength` as its second argument. To set them for the whole app, put them under `'password-field'` in a [`LabelsProvider`](/docs/localization). Functions get the numbers and names that go in the sentence.

```ts
const defaultPasswordFieldLabels: PasswordFieldLabels = {
  reveal: 'Show password',
  strength: 'Password strength',
  empty: 'Empty',
  weak: 'Weak',
  fair: 'Fair',
  good: 'Good',
  strong: 'Strong',
  avoidCommon: 'Avoid common passwords and words.',
  useLength: 'Use at least 12 characters.',
  avoidSequences: 'Avoid runs like abcd or 1234.',
  avoidRepeats: 'Avoid repeating the same character.',
  mixCharacters: 'Mix in capitals, numbers or symbols.',
  addLength: 'A few more characters would make it strong.',
  ruleLength: 'At least 12 characters',
  ruleCase: 'A lowercase and an uppercase letter',
  ruleNumber: 'A number',
  ruleSymbol: 'A symbol',
}
```
