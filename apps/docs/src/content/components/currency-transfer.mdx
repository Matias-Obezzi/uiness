A transfer that tracks itself: the amount converts in place once the money changes currency, the steps fill a rail as they pass, and a reference to copy closes it.

## Usage

```tsx
import { CurrencyTransfer } from '@/components/ui/currency-transfer'

<CurrencyTransfer
  amount={250}
  from="USD"
  to="EUR"
  rate={0.92}
  steps={[{ label: 'Received' }, { label: 'Converted' }, { label: 'Delivered' }]}
  current={transfer.step}
  reference={transfer.id}
/>
```

`current` is the step under way; past the last one the transfer is complete and the reference shows with a [Copy Button](/docs/components/copy-button). The amount rolls with an [Odometer](/docs/motion/odometer) from `convertAt` on.

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `amount` |  | What is sent, in `from`. |
| `from, to` |  | ISO codes. |
| `rate` |  | How many `to` one `from` buys. |
| `steps` |  | Each `{ label, detail? }`. |
| `current` |  | The step under way. |
| `convertAt` | `1` | From this step the amount shows converted. |
| `reference` |  | Shown with a copy button at the end. |

## Accessibility

The steps are a list, the current one marked as the current step, and each says whether it is done, in progress or to come. The amount is a polite live region.

## Labels

Every word it shows or reads out to screen readers, in English by default. `CurrencyTransfer` takes them as `labels`. To set them for the whole app, put them under `'currency-transfer'` in a [`LabelsProvider`](/docs/localization).

```ts
export const defaultCurrencyTransferLabels: CurrencyTransferLabels = {
  rate: (from, rate, to) => `1 ${from} = ${rate} ${to}`,
  reference: 'Reference',
  stepState: (state) =>
    state === 'done' ? 'done' : state === 'current' ? 'in progress' : 'to come',
}
```
