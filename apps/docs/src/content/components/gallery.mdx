Click any picture. It flies from its thumbnail to the center of the screen and back when you close it. Arrow keys, swipe and the thumbnail strip move between images.

## Usage

```tsx
import { Gallery } from '@/components/ui/gallery'

const images = [
  { src: '/photos/dawn.jpg', placeholder: dawnTiny, alt: 'Dawn at the lake', caption: 'Dawn' },
  { src: '/photos/noon.jpg', placeholder: noonTiny, alt: 'Noon at the lake' },
]

<Gallery images={images} columns={{ base: 1, sm: 2, md: 3 }} aspect="3 / 2" />
```

## Columns

Columns follow the gallery's own width, not the screen's. They are set with container queries, so a gallery in a narrow side column stacks while the same gallery in the main column spreads out, on a phone or on a wide monitor alike. Both below have the same `columns`.

<ComponentPreview name="gallery-responsive" align="start" />

Pass a number for the same count everywhere past the narrowest widths, or an object with a count per breakpoint. A breakpoint left out keeps the count of the one below it.

| Key | Gallery width |
| --- | --- |
| `base` | Any. Default `1` when an object leaves it out. |
| `sm` | 24rem (384px) and up. |
| `md` | 36rem (576px) and up. |
| `lg` | 48rem (768px) and up. |
| `xl` | 64rem (1024px) and up. |

A number keeps the shorthand it always had: two columns while narrow (three for five or more), then the full count from `md`. `columns={4}` is `{ base: 2, md: 4 }`.

The gallery is the size container, so it takes its width from its parent and is `w-full` by default. Inside a flex row, give it a width (or `flex-1 min-w-0`): a size container does not grow to fit its content.

## Without the lightbox

`openOnClick={false}` makes the cells plain pictures: no buttons on the tab order, and each image gets its own `alt` now that no button carries the name. Pass `onImageClick` to handle a press yourself — the cells stay buttons and call it, and with `openOnClick` on, `event.preventDefault()` inside it keeps the lightbox shut.

<ComponentPreview name="gallery-static" align="start" />

```tsx
<Gallery images={images} openOnClick={false} gap="1rem" radius="0" zoom={1.08} />
```

## Grid only

`GalleryGrid` is the grid without the lightbox, in its own file. It has no `'use client'` and no JavaScript of its own, so it renders as a server component, and none of the viewer or the dialog library ends up in your bundle. It takes the same `columns`, `gap`, `aspect`, `radius` and `zoom`, and lays out by its own width in the same way.

<Install name="gallery-grid" extra="Only the grid: no Image component, no lightbox." />

Pictures are plain lazy `img` elements by default. Pass `renderImage` to draw them with your own image component, for resized and optimized files. It gets the `image`, its `index`, the `src` to show (`thumbnail` or `src`), the `alt` and a `className` that fills the cell and does the hover zoom.

```tsx
import { GalleryGrid } from '@/components/ui/gallery-grid'

<GalleryGrid
  images={images}
  columns={{ base: 2, md: 4 }}
  renderImage={({ src, alt, className, image }) => (
    <OptimizedImage src={src} alt={alt} width={image.width} height={image.height} sizes="25vw" className={className} />
  )}
/>
```

`Gallery` takes `renderImage` too, for the grid; the lightbox keeps showing `src` at full size. To make cells buttons without the lightbox, `getItemProps(index, image)` returns props for each cell's `button`: an `onClick`, its `aria-label`. That needs a client component, since it passes functions.

## Images

| Field | Description |
| --- | --- |
| `src` | Full size image, shown in the lightbox. |
| `thumbnail` | Smaller file for the grid. Defaults to `src`. |
| `placeholder` | Tiny version for the blur transition in the grid. |
| `alt` | Describes the image, also used as the lightbox title. |
| `caption` | Shown under the image in the lightbox. |
| `width`, `height` | Intrinsic size, keeps the grid stable before the image loads. |

## Props

### Gallery

| Prop | Default | Description |
| --- | --- | --- |
| `columns` | `3` | A number, or `{ base, sm, md, lg, xl }` by the gallery's own width. See [Columns](#columns). |
| `gap` | `'0.5rem'` | Space between cells. Any CSS length. |
| `aspect` | `'1 / 1'` | Aspect ratio of the cells. |
| `radius` | the theme's `--radius` | Corner radius of the cells. Any CSS length. |
| `zoom` | `true` | Scale on hover: `true` for 1.03, `false` for none, or a number such as `1.1`. Never with reduced motion. |
| `openOnClick` | `true` | Open the lightbox when a cell is pressed. |
| `onImageClick` | | `(index, event)` on a press. `event.preventDefault()` keeps the lightbox shut. |
| `thumbnails` | `true` | Thumbnail strip in the lightbox. |
| `container` | `document.body` | Element the lightbox portals into. |
| `renderImage` | `Image` with blur-up | Draws a grid picture with your own image component. See [Grid only](#grid-only). |

`className` and the other `div` props go on the outer element, the size container. The grid inside it is `data-slot="gallery-grid"`.

### Lightbox

| Prop | Default | Description |
| --- | --- | --- |
| `images`, `index`, `onIndexChange` | | The images and which one shows. |
| `open`, `onOpenChange` | | Controlled open state. |
| `origin`, `getOrigin` | | Rects to fly in from and back to. |
| `getReturnFocus` | | `(index) => element` to focus on close. Without it, focus goes back to what had it on open. |
| `loop` | `true` | Wrap around at the ends. |
| `thumbnails` | `true` | Thumbnail strip. |
| `closeOnBackdrop` | `true` | Close on a tap or click on the dark space around the image. |
| `container` | `document.body` | Element to portal into. |

## Lightbox on its own

`Lightbox` is exported too. Control it with `open`, `index` and their change handlers, and pass an `origin` rect if you want the fly-in animation from somewhere on the page.

```tsx
import { Lightbox } from '@/components/ui/gallery'

<Lightbox images={images} index={index} onIndexChange={setIndex} open={open} onOpenChange={setOpen} />
```

It needs no `Dialog.Trigger`. On close, focus goes back to whatever had it when the lightbox opened, or to the element `getReturnFocus` returns; `Gallery` uses that to focus the thumbnail of the image last shown, so the reader picks up where they left off.

### Inside an iframe

The lightbox portals into `document.body` of the document the code runs in. When the gallery renders into an iframe from the parent page, as a page editor's canvas does, that is the wrong page. Pass the frame's body:

```tsx
<Gallery images={images} container={frame.contentDocument?.body} />
```

## Keyboard and touch

Arrow keys move, Escape closes, focus stays inside the viewer. On touch, swipe sideways to move and down to close. A tap or click on the dark backdrop closes too; it is decided on release and only when the press both started and ended on the backdrop without moving, so a swipe that happens to end there does not close. `prefers-reduced-motion` turns the flight into a plain fade and drops the hover zoom.

## Labels

Every word it shows or reads out to screen readers, in English by default. `Gallery` and `Lightbox` take them as `labels`. To set them for the whole app, put them under `'gallery'` in a [`LabelsProvider`](/docs/localization). Functions get the numbers and names that go in the sentence.

```ts
const defaultGalleryLabels: GalleryLabels = {
  open: (index, alt) => (alt ? `Open ${alt}` : `Open image ${index}`),
  image: (index, count) => `Image ${index} of ${count}`,
  help: 'Use the arrow keys to move between images and Escape to close.',
  close: 'Close',
  previous: 'Previous image',
  next: 'Next image',
  show: (index) => `Show image ${index}`,
}
```
