Lines over days or categories, straight or smooth, with an optional area fill, from a list of series. It is a ready-made [Chart](/docs/components/chart): recharts underneath, with the dates, formats, legend and empty state already handled.

## Usage

```tsx
import { LineChart } from '@/components/ui/line-chart'

<LineChart
  area
  curve="monotone"
  data={data}
  x="date"
  series={[
    { key: 'visitors', label: 'Visitors' },
    { key: 'returning', label: 'Returning' },
  ]}
/>
```

`curve="monotone"` draws a smooth curve that never overshoots the points, so a peak in the line is always a peak in the data. `area` adds a fading wash of each series color under its line.

The y axis keeps zero by default. Set `includeZero={false}` to zoom into the range of the data, for values that never get near zero.

## Missing values

A row whose value is `null`, missing or not a number breaks the line, instead of drawing a straight bridge across days with no data. A lone value between two gaps shows as a dot.

## Reading values

Hover anywhere over the chart for the nearest row: a vertical line marks it and the tooltip lists every series. The chart takes focus too, and the left and right arrow keys move through the rows. Screen readers get a summary of the series and the date range.

The dots on the active row have a ring in the page color, so they stay readable where lines cross. Inside a card, point it at the card color:

```tsx
<LineChart style={{ '--chart-surface': 'var(--card)' } as React.CSSProperties} {...props} />
```

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `data` | | Rows to plot, in order. |
| `x` | | Key of the x value in each row. Dates, ISO date strings, strings or numbers. |
| `series` | | `{ key, label?, color? }` per series. Colors default to `--chart-1` to `--chart-5` in order. |
| `curve` | `'linear'` | `'linear'` or `'monotone'`. |
| `area` | `false` | Fill under each line. |
| `includeZero` | `true` | Keep zero on the y axis. |
| `height` | `240` | Height of the chart, legend excluded. |
| `xFormat` | short date | Formats x values on the axis and in the tooltip. |
| `yFormat` | compact number | Formats values on the axis and in the tooltip. |
| `locale` | browser | Locale of the default formats. |
| `showGrid` | `true` | Horizontal gridlines. |
| `showLegend` | two series or more | Legend above the chart, click to toggle a series. |
| `empty` | `"No data"` | Shown when there is nothing to plot. |
| `aria-label` | generated | Replaces the generated summary. |

For anything these props do not cover, write the recharts chart yourself inside a [`ChartContainer`](/docs/components/chart).

## Labels

Every word it shows or reads out to screen readers, in English by default. Pass the ones to change as `labels`. To set them for the whole app, put them under `'chart'` in a [`LabelsProvider`](/docs/localization). Functions get the numbers and names that go in the sentence.

The words are shared by every chart, under `chart`.

```ts
const defaultChartLabels: ChartLabels = {
  empty: 'No data',
  summary: (series, points, from, to) =>
    `${series.join(', ')}, ${points} ${points === 1 ? 'point' : 'points'}${points ? `, from ${from} to ${to}` : ''}`,
  barChart: (summary) => `Bar chart of ${summary}`,
  lineChart: (summary) => `Line chart of ${summary}`,
}
```
