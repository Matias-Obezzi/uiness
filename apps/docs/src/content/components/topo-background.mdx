A living contour map that drifts slowly, rises in a hill under the pointer and ripples out from a press.

## Usage

```tsx
import { TopoBackground } from '@/components/ui/topo-background'

<TopoBackground className="h-96 rounded-xl border">
  <h1>Your headline</h1>
</TopoBackground>
```

It draws on a canvas behind its children with the `useCanvas` hook, sized to the box and capped at twice the pixel ratio, and stops drawing while it is off screen. The contours take the text colour, every fifth one a little bolder.

## Props

| Prop | Default | Description |
| --- | --- | --- |
| `className` |  | Sets its size and lays out the children, like any div. |

## Accessibility

The canvas is decoration behind the content: your children stay plain, selectable text. The contours stay faint, so text over them keeps its contrast. With reduced motion it draws a still frame and only answers the pointer.
