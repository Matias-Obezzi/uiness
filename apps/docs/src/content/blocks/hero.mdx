The first section of a page: what it is, why it matters, and what to do next. Every block takes its words through props and lays itself out by the width of its container, so it works in a full page, a sidebar layout or a panel.

## Hero 01

A centered hero with an announcement pill, a headline that ends in a flowing gradient, a lead paragraph and two actions, over a grid that fades out.

<BlockPreview name="hero-01" />

<Install name="hero-01" />

```tsx
import { Hero01 } from '@/components/hero-01'

<Hero01
  announcement={{ label: 'Version 2 is out', href: '/changelog' }}
  title="Plan the week in"
  highlight="five minutes"
  description="One calendar for the team, the tasks and the time in between."
  primaryAction={{ label: 'Start free', href: '/signup' }}
  secondaryAction={{ label: 'See a demo', href: '/demo' }}
/>
```

| Prop | Description |
| --- | --- |
| `announcement` | `{ label, href }` for the pill above the headline. `null` hides it. |
| `title` | The headline before the highlighted words. |
| `highlight` | The words at the end, filled with a flowing gradient. |
| `description` | The lead paragraph. |
| `primaryAction`, `secondaryAction` | `{ label, href }` for the two buttons. `null` hides one. |
| `note` | A short line under the buttons. |

## Hero 02

A split hero: eyebrow, headline, lead, two actions and a row of small figures on one side, and the product on a card that tilts towards the pointer on the other. The columns stack when the container is narrow.

<BlockPreview name="hero-02" />

<Install name="hero-02" />

```tsx
import { Hero02 } from '@/components/hero-02'

<Hero02
  eyebrow="Planning for small teams"
  title="Plan the week in five minutes"
  description="One calendar for the team, the tasks and the time in between."
  primaryAction={{ label: 'Start free', href: '/signup' }}
  secondaryAction={{ label: 'See a demo', href: '/demo' }}
  stats={[
    { value: '3x', label: 'faster planning' },
    { value: '8k', label: 'teams' },
    { value: '4.8/5', label: 'rating' },
  ]}
  image={{ src: '/screenshot.png', alt: 'The week view with tasks and meetings' }}
/>
```

| Prop | Description |
| --- | --- |
| `eyebrow` | The small line above the headline. `null` hides it. |
| `title` | The headline. |
| `description` | The lead paragraph. |
| `primaryAction`, `secondaryAction` | `{ label, href }` for the two buttons. `null` hides one. |
| `stats` | `{ value, label }[]` shown in a row under the buttons. `null` hides it. |
| `image` | `{ src, alt }` for a screenshot on the tilting card. Without it, a drawn product mockup takes its place. |
| `badge` | `{ value, label }` for the small card floating over the corner of the picture. `null` hides it. |

## Hero 03

A centered headline, lead and actions above a browser window, with the phone app hanging off its corner. Both rise in as they come into view; when the container is narrow the phone moves under the browser instead of covering it.

<BlockPreview name="hero-03" />

<Install name="hero-03" />

```tsx
import { Hero03 } from '@/components/hero-03'

<Hero03
  eyebrow="Web and mobile"
  title="Your whole week, on every screen you own"
  description="Plan on the big screen, check off on the go."
  primaryAction={{ label: 'Start free', href: '/signup' }}
  secondaryAction={{ label: 'Get the app', href: '/app' }}
  desktop={{ url: 'app.example.com/week', src: '/week.png', alt: 'The week view' }}
  mobile={{ src: '/today.png', alt: 'Today on the phone' }}
/>
```

| Prop | Description |
| --- | --- |
| `eyebrow` | The small line above the headline. `null` hides it. |
| `title`, `description` | The headline and the lead paragraph. |
| `primaryAction`, `secondaryAction` | `{ label, href }` for the two buttons. `null` hides one. |
| `desktop` | `{ url, src, alt }`: the address in the browser bar and its screenshot. |
| `mobile` | `{ src, alt }` for the phone screenshot. `null` leaves only the browser. |

## Hero 04

A launch hero for a game: the title scrambles into place over a synthwave floor, inside the brackets of a HUD, with a live season line, the platforms it runs on and counts that tick up. Corners cut at 45° and glows in the primary color give it the look of a game's menu.

<BlockPreview name="hero-04" />

<Install name="hero-04" />

```tsx
import { Hero04 } from '@/components/hero-04'

<Hero04
  eyebrow="Season 04 · Now live"
  title="Neon Drift"
  tagline="// Race the grid. Own the night."
  primaryAction={{ label: 'Play free', href: '/play' }}
  secondaryAction={{ label: 'Watch trailer', href: '/trailer' }}
  platforms={['PC', 'PlayStation 5', 'Xbox Series']}
  stats={[{ label: 'Players online', value: 184320 }]}
/>
```

| Prop | Description |
| --- | --- |
| `eyebrow` | The line above the title, with a live dot. `null` hides it. |
| `title` | The game's name, as plain text: it scrambles into place. |
| `tagline`, `description` | The mono line under the title and the paragraph. |
| `primaryAction`, `secondaryAction` | `{ label, href }` for the two buttons. `null` hides one. |
| `platforms` | Where it runs, in a row. |
| `stats` | `{ label, value, suffix? }[]`, counted up as they come into view. |
