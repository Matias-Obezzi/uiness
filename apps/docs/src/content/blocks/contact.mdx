Ways to get in touch, with a form that tells you it worked. Every block takes its words, channels and offices through props and lays itself out by the width of its container.

## Contact 01

A contact form that checks each field as you leave it and points at what is missing, then turns into a confirmation in place, easing its height between the two. Beside it, cards for the other ways to reach you; under it, an office card per city with the local time there, ticking, and whether the office is open.

```tsx
import { Contact01 } from '@/components/contact-01'

<Contact01
  brand={{ name: 'Juniper', domain: 'juniper.app' }}
  title="Get in touch"
  minMessage={10}
  onSubmit={async (values) => {
    const res = await fetch('/api/contact', { method: 'POST', body: JSON.stringify(values) })
    if (!res.ok) throw new Error('Your message did not go through. Try again in a minute.')
  }}
  offices={[
    { city: 'Berlin', address: 'Torstraße 1, 10119', timeZone: 'Europe/Berlin' },
    { city: 'Austin', address: '500 W 2nd St, TX 78701', timeZone: 'America/Chicago', hours: [8, 17] },
  ]}
/>
```

| Prop | Description |
| --- | --- |
| `brand` | `{ name, domain? }`. The default description names the brand, and the default channels write to `sales@` and `press@` its domain. Default `Acme` at `acme.com`. |
| `eyebrow`, `title`, `description` | The words above the channels. `null` hides the eyebrow or the description. |
| `onSubmit` | Called with `{ name, email, company, message }` once every field passes. Return a promise to show the pending state; throw an `Error` to show its message and keep what was typed. |
| `minMessage` | Shortest message accepted, in characters. Default `20`. |
| `channels` | `{ icon?, title, description, label, href }[]` for the cards beside the form, in place of the defaults for the brand. An empty list hides them. |
| `offices` | `{ city, address, timeZone, hours? }[]`. `timeZone` is an IANA name; `hours` is `[open, close]` on weekdays, default `[9, 18]`. An empty list hides them. |
| `locale` | Locale for the clocks. Defaults to the browser's. |
| `labels` | Field labels, messages and button text: `name`, `email`, `company`, `message`, `required`, `invalidEmail`, `tooShort`, `successTitle`, `successDescription`, `open`, `closed` and more. |

The clocks show `--:--` until the page is running in the browser, so a server render and the first client render agree.
