Screens for getting people in: signing in, signing up, getting back into an account. Every block takes its words through props and lays itself out by the width of its container, so it works in a full page, a sidebar layout or a panel.

## Auth 01

A sign in form with email and password, a forgotten password link, a submit button that shows it is waiting, and buttons for other providers. On a wide container a panel with a customer quote sits beside it.

```tsx
import { Auth01 } from '@/components/auth-01'

<Auth01
  title="Sign in to Summit"
  onSubmit={async ({ email, password }) => {
    const res = await fetch('/api/login', {
      method: 'POST',
      body: JSON.stringify({ email, password }),
    })
    if (!res.ok) throw new Error('That email and password do not match.')
  }}
  providers={[{ id: 'github', label: 'GitHub' }]}
  onProvider={(id) => signIn(id)}
  signUp={{ prompt: 'No account yet?', label: 'Sign up', href: '/signup' }}
/>
```

| Prop | Description |
| --- | --- |
| `brand` | `{ name, href, icon? }` for the wordmark above the form. |
| `title`, `description` | The heading and the line under it. |
| `onSubmit` | Called with `{ email, password }`. Return a promise to show the pending state; throw an `Error` to show its message. |
| `forgotPasswordHref` | Where "Forgot password?" goes. `null` hides it. |
| `providers` | `{ id, label, icon? }` for the buttons under the divider. An empty list hides them. |
| `onProvider` | Called with a provider's `id` when its button is pressed. |
| `signUp` | `{ prompt, label, href }` for the line under the form. `null` hides it. |
| `testimonial` | `{ quote, name, role?, image? }` for the side panel on wide containers. `null` hides the panel. |
| `labels` | Field labels and button text: `email`, `password`, `forgotPassword`, `submit`, `pending`, `divider`, `continueWith`, `error` and more. |
